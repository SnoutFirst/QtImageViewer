## About QtImageViewer
A basic Qt Widgets image viewer with slideshow and shuffle

## WebAssembly Demo

Try the live WebAssembly demo:
- Main: [https://SnoutFirst.github.io/QtImageViewer/](https://SnoutFirst.github.io/QtImageViewer/)
- Develop: [https://SnoutFirst.github.io/QtImageViewer/develop/](https://SnoutFirst.github.io/QtImageViewer/develop/)

The `main` branch deploys to the root, `develop` to `/develop/`, and tags to `/tagname/`.
